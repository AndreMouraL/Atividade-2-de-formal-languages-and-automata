# Teoria das Linguagens Formais - Exercícios em Python

Este repositório contém exercícios e exemplos práticos sobre conceitos fundamentais da Teoria das Linguagens Formais, implementados em Python. Os tópicos abordados incluem:

- **Conjuntos de Cadeias**: Geração de Σⁿ e Σ*.
- **Operações e Propriedades**: Concatenação, reversão, prefixo/sufixo próprio.
- **Fechamento Transitivo e Reflexivo**: Cálculo de L*.
- **Quociente de Linguagens**: Implementação e exemplos.
- **Substituição entre Alfabetos**: Transformação de cadeias e linguagens.
